# Python learning series #011–#020

All examples are standard-library Python, with no pip dependencies.

Run a single example from the repository root:

```shell
python python/episodes/012-python-equality-identity/demo.py
```

Run the automated verification suite:

```shell
python -m unittest discover -s python/tests -v
```

Each episode contains `README.md` and a runnable `demo.py`; `catalog.json` stores the original explained behavior, expected console output, and educational caveats.

**Availability:** These resources are eligible to be published before the associated videos. This repository itself is not live until created and published from the dedicated Logic Nudge account.
